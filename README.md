# GUI Themes (Fabric, Minecraft 1.20.1)

Три темы интерфейса: **Тёмная**, **Кошачья**, **Неон** (+ «Обычная» — выключено).

- Сменить тему: кнопка «Тема: …» в правом верхнем углу главного меню, меню паузы и настроек
- Или клавиша **F6** прямо в игре (настраивается в «Управление»)
- Выбор сохраняется в `config/guithemes.properties`

## Сборка без установки программ (GitHub Actions)
1. Создай репозиторий на github.com, загрузи в него все файлы из этой папки (вместе с папкой `.github`).
2. Открой вкладку **Actions** → запустится сборка `build` (≈2–3 минуты).
3. Внутри завершённого запуска скачай артефакт `guithemes-mod`, достань `guithemes-1.0.0.jar`.
4. Положи jar в `mods` (нужны Fabric Loader 0.15+ и Fabric API для 1.20.1, Java 17).

## Сборка у себя
JDK 17 + Gradle 8.10: `gradle build` → `build/libs/guithemes-1.0.0.jar`
